THE FRICTION

Problem

Booking information sat in disconnected systems. Invoices required manual drafting, while vehicle condition before and after a booking lacked a consistent paper trail.

MY CONTRIBUTION

Solution

I developed an admin dashboard for fleet and booking management, automated personalised invoice generation from booking data, added invoice email delivery, and structured pre- and post-booking condition records.

PROCESS VALUE

Outcome

The workflow removes repeated invoice drafting and data re-entry, supports consistent customer communication, and creates a clearer booking and vehicle-condition history. Time savings have not yet been formally measured.

HOW I WORK

The process comes first.

Software is the intervention. Understanding the operation is where the work begins.

01

Understand

Map the current workflow, listen to the people doing the work and identify where effort gets lost.

02

Diagnose

Use root cause analysis and process data to distinguish symptoms from the underlying constraint.

03

Build

Develop interfaces and automations that connect the right information to the next action.

04

Improve

Review the workflow with users, test the handoffs and refine the system against operational needs.
